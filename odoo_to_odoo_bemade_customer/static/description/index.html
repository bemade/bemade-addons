Odoo to Odoo Bemade Customer

Solution de synchronisation dédiée pour les clients de Bemade

Présentation

Le module Odoo to Odoo Bemade Customer est spécialement conçu pour les clients de Bemade qui souhaitent synchroniser leurs données avec la plateforme Bemade. Il offre une solution clé en main avec une configuration simplifiée, spécifiquement adaptée aux besoins des clients.

Fonctionnalités

  • Connexion sécurisée et authentifiée à la plateforme Bemade
  • Configuration automatique des modèles et champs standards
  • Interface simplifiée pour les administrateurs
  • Synchronisation bidirectionnelle des données
  • Journalisation détaillée et gestion des erreurs adaptée aux clients
  • Reprise automatique sur erreur
  • Monitoring intégré des activités de synchronisation

Différence avec le module Bemade standard

Contrairement au module odoo_to_odoo_bemade qui est conçu pour des intégrations personnalisées et complexes, ce module est spécifiquement développé pour simplifier l'expérience des clients Bemade:

Fonctionnalité odoo_to_odoo_bemade odoo_to_odoo_bemade_customer
Configuration Manuelle et détaillée Automatique et simplifiée
Cible Développeurs et intégrateurs Utilisateurs finaux et administrateurs
Connexion Multiple et configurable Spécifique à Bemade.org
Interface Technique et complète Simplifiée et adaptée aux clients

Architecture

Ce module s'appuie sur l'architecture de base du module odoo_to_odoo_sync et étend les modèles avec une couche spécifique aux clients Bemade. Il étend les modèles suivants:

  • odoo.sync.model → odoo.to.bemade.customer.sync.model
  • odoo.sync.model.field → odoo.to.bemade.customer.sync.model.field
  • odoo.sync.queue → odoo.to.bemade.customer.sync.queue
  • odoo.sync.log → odoo.to.bemade.customer.sync.log
  • odoo.sync.manager → odoo.to.bemade.customer.sync.manager

Cette architecture permet une expérience utilisateur optimisée tout en bénéficiant de la robustesse du système de synchronisation de base.

Installation

L'installation est simplifiée pour les clients Bemade:

  1. Installez ce module depuis le catalogue d'applications Bemade
  2. Entrez votre clé d'API Bemade (fournie par votre gestionnaire de compte)
  3. Sélectionnez les données à synchroniser dans l'assistant
  4. La synchronisation initiale démarre automatiquement
