Odoo to Odoo Bemade

Connecteur universel pour la synchronisation avec Bemade

Présentation

Le module Odoo to Odoo Bemade fournit une couche intermédiaire spécialisée entre le module de base odoo_to_odoo_sync et les implémentations spécifiques aux clients. Il introduit des fonctionnalités adaptées à l'écosystème Bemade.

Fonctionnalités

  • Extension des modèles de synchronisation de base avec des fonctionnalités spécifiques à Bemade
  • Gestion des transformations avancées pour les champs synchronisés
  • Interface d'administration simplifiée pour la configuration Bemade
  • Support multi-instances pour les environnements complexes
  • Historique détaillé des synchronisations avec diagnostic amélioré

Architecture

Ce module s'appuie sur l'architecture de base du module odoo_to_odoo_sync et ajoute une couche spécifique à Bemade. Il étend les modèles suivants:

  • odoo.sync.model → odoo.to.bemade.sync.model
  • odoo.sync.model.field → odoo.to.bemade.sync.model.field

Cette architecture en couches permet une séparation claire entre la logique de synchronisation générique et les besoins spécifiques de l'environnement Bemade.

Installation

Pour installer ce module, vous devez d'abord installer le module de base odoo_to_odoo_sync.

  1. Assurez-vous que le module odoo_to_odoo_sync est installé
  2. Installez ce module odoo_to_odoo_bemade
  3. Configurez les paramètres spécifiques à Bemade dans le menu Administration

Configuration

La configuration se fait en plusieurs étapes:

  1. Définir les instances Bemade auxquelles se connecter
  2. Configurer les modèles à synchroniser
  3. Configurer les champs pour chaque modèle avec leurs transformations spécifiques
  4. Activer la synchronisation automatique si nécessaire
