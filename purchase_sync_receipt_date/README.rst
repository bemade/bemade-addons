This module adds the ability to automatically synchronize the scheduled date on incoming
receipts when the expected date on a purchase order line is updated.

By default, Odoo only updates the deadline date on stock moves, but not the actual
scheduled date that appears on the receipt. This module bridges that gap.

Configuration
=============

To enable this feature:

1. Go to Purchase > Configuration > Settings
2. Enable "Sync Receipt Scheduled Date" under the Orders section
3. Click Save

Usage
=====

Once enabled, any changes to the "Expected Arrival" date on a purchase order line will
automatically update the "Scheduled Date" on the related receipt, as long as the receipt
is not yet done or cancelled.
