Author: Bemade Inc.
Website: www.bemade.org
License: LGPL-3

Description

This module provides a professional customer account statement report that displays outstanding invoices for your customers. Generate clear, detailed statements showing unpaid and partially paid invoices with all relevant information.

Features

  • Generate account statements directly from customer records
  • Display all unpaid and partially paid invoices
  • Show invoice details: number, date, due date, PO reference
  • Calculate and display total invoiced, paid, and outstanding amounts
  • Multi-currency support
  • Professional PDF output with company branding
  • Easy access from partner form view Print menu

Usage

  1. Navigate to a customer record in the Contacts app
  2. Click on the "Print" button in the top menu
  3. Select "Customer Account Statement"
  4. A PDF report will be generated showing all outstanding invoices

Technical Information

Dependencies: account
Report Model: res.partner
Report Type: QWeb PDF
